# FITLOG

HTML과 CSS로 만든 간단한 운동 관리 웹사이트입니다.

## 파일 구성
- `index.html`: 메인 화면
- `workouts.html`: 운동 목록 및 운동 설명
- `routine.html`: 오늘의 운동 체크리스트
- `guide.html`: 운동 전 확인할 가이드
- `style.css`: 모든 페이지에 공통으로 적용되는 디자인

## 사용 기술
- HTML
- CSS

## 실행 방법
`index.html` 파일을 브라우저에서 열면 됩니다. 다른 페이지는 상단 메뉴를 눌러 이동할 수 있습니다.

## 참고
이 프로젝트는 HTML과 CSS만 사용합니다. 체크리스트는 현재 페이지에서만 표시되며, 새로고침하면 체크 상태가 초기화됩니다. 운동 기록 저장 기능은 포함되어 있지 않습니다.
